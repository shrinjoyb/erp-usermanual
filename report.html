Login Page

Users can log in to the system using valid credentials to access authorized features.

Report Section Overview

Users can generate various types of reports from this section according to their specific requirements.

Report Dashboard

Through this section, authorized users and administrators can generate and access various reports using the available options.

Registration Report

In this section, authorized users can generate registration report status by selecting the required criteria from the dropdown menus.
  • Generate registration reports based on College, Course, and Semester.
  • Generate an overall registration report.
  • Download student registration data in Excel format.
  • Download Banglar Uchcha Shiksha Portal registration data in Excel format.
Here, users can search the registration status by selecting a specific college name..

Student Form Fill-up Status Report

In this section, authorized users can search the Academic Cum Examination Enrollment Report by selecting the required options from the dropdown menu.

  • Search reports based on College, Course Category, and Semester.
  • Generate an overall enrollment report.
  • Download student enrollment data in Excel format.

Search Academic Cum Examination Enrollment Report

To generate the Academic Cum Examination Enrollment Report, users must select the required criteria from the dropdown menus.

Overall Enrollment Report

To generate the overall enrollment report, users are required to select the relevant options from the dropdown menus.

Student Enrollment Data (Excel)

To download the student enrollment data in Excel format, users must select the necessary criteria from the dropdown menus.

DR Sheet Report

In this section, users can download the DR Sheet by selecting the DR Sheet download option.

To download the DR Sheet, users must fill in all the required details accurately before proceeding.

Marks Submission Status Report

In this section, users can download the marks submission status data by clicking the “Marks Submission” button.

Users can view the Marks Submission Status records using the following options:

  • View the overall Marks Submission Status report.
  • View the Marks Submission Status for a specific college.

Marks Submission Status – Overall Report

In the case of the Overall Report option, users must fill in all the required details. After submitting the details, the following actions can be performed:

  • Download the Marks Submission Status in Excel format.
  • View the Marks Submission Status using the Web View option.
  • Download Student Marks in Excel format.

Marks Submission Status for a Specific College

In this section, users must fill in all the required details and click the “Search” button. Based on the selected criteria, a list of records will be displayed at the bottom of the page.

Users can generate and download the report in PDF format by clicking the “Export to PDF” button.

View Marks for a Particular Discipline

From the three-dot (more options) menu, users can view the marks of a specific student by selecting the “View” option.

This section displays an example of marks for a particular discipline.

Student Marksheet Download

In this section, users can download the student marksheet by clicking the “Marksheet” option.

Users must select the required details from the dropdown menus to download the marksheet data in Excel format for a specific academic session and discipline.

This option allows users to retrieve the marksheet of a particular student by providing the student registration number.

Web Result View

Users can also view the marks results directly in the lower section of the web page.

Individual Marksheet View

By clicking the “Eye” button, users can view the individual marksheet of each student.

By clicking the “Export to Excel” button, users can download the marksheet data in Excel format.
