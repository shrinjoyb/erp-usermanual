Paper Setter Module

1. Paper Setter List

The dashboard serves as the central repository for managing examiner data. It displays a comprehensive Paper Setter List containing all registered personnel currently in the system.

Available Actions:
  • Export Data: Users can download the entire list in Excel format by clicking the Export to Excel button.
  • Search Records: Locate specific paper setters quickly using the Search option.
  • Manage Records: Users can update details or remove a setter using the Edit and Delete buttons respectively.

2. Add Paper Setter

To onboard a new examiner, navigate to the top right corner of the dashboard and click the "Add Paper Setter" button. This action will redirect you to the registration interface.

3. Paper setter Add Form

The registration form allows the user to input all necessary details to create a new paper setter profile manually. Ensure all mandatory fields are filled correctly before submission.

Bulk Upload via Excel

For adding multiple paper setters simultaneously, the system provides a Bulk Upload feature.

Prerequisite: Users must download the specific Excel template provided below to ensure data compatibility.
Download Excel Template

Click here to download the Paper Setter Template (.xlsx)

Steps to Upload:

  1. Fill in the required details for all setters in the downloaded Excel sheet.
  2. Click the "Choose File" button and select the prepared file from your system.
  3. Finally, click "Upload File" to complete the batch registration process.
