Question Paper Viewer Management

This module facilitates the management of users authorized to view question papers. After clicking this option from the main dashboard, the user is redirected to the Question Paper Viewer List dashboard.

Initiate New Viewer Registration

From this section, the administrator can start the process of onboarding a new viewer by clicking the "Add New Question Paper Viewer" button located on the interface.

Add Viewer Form

In this section, the user can register a new viewer. The system requires the user to select the appropriate details (such as Faculty Name, Department, etc.) from the provided dropdown menus to ensure accurate assignment.

Question Paper Viewer List

This section displays the complete list of assigned question paper viewers. Administrators can manage these records directly from the list view.

Management Actions:

Users can perform the following actions on existing records:

  • Edit: Modify the details of a viewer.
  • Delete: Remove a viewer from the system permanently.
