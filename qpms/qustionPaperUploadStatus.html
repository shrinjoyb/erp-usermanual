QP Upload Status

This section allows the user to view the overall status of question paper uploads within the system. It provides a centralized dashboard to track submission progress across different subjects and courses.

Question Paper Upload Status Report

This screen displays the detailed question paper upload status report. To view specific records, the user can search for question papers by filling in the required details (e.g., Session, Exam Type, Subject) in the filter fields.

Question Paper List View

This section displays the list of question papers along with their current submission status. The system uses visual indicators to denote progress.

Status Indicators & Actions:
  • Green Mark Denotes that the question paper has been successfully submitted by the setter.
  • White Mark Denotes that the question paper has not yet been submitted.
  • Action: The administrator can extend the upload deadline for a specific paper by clicking the Extend option.
