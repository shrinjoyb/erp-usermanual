Appointment Letter Module

1. Appointment Letter Overview

This module provides a comprehensive interface for administrators to view, manage, and distribute appointment letters to Question Paper Setters.

2. Search Appointee

To find a specific appointee, the user must fill in the required details (such as Exam Year, Subject, Paper, etc.) in the filter fields and click the Search button.

3. Question Paper Setter Appointment List

Upon searching, the system displays the Appointment List. This list categorizes appointees based on their submission status using visual indicators.

Status Legend:
  • Green Mark Indicates appointees who have successfully submitted the question paper.
  • White Mark Indicates appointees who have not yet submitted the question paper.

4. View & Send Appointment Letter

The administrator can perform the following actions for each appointee in the list:

Send Mail Option

Clicking the "Send Mail" button triggers the system to email the official appointment letter directly to the appointee's registered email address.

View Option

Clicking the "View" button opens a preview of the generated appointment letter on the screen for verification purposes.
