Faculty Bank Details

This section allows the user to access and view the banking information of faculty members registered within the system. It ensures that administrative users can verify payment-related details efficiently.

Faculty Bank Details Dashboard

The Faculty Bank Details Dashboard provides a search interface for locating specific employee records.

Search Functionality:

Users can filter the database by filling in required fields such as Academic Session, Semester etc.

Employee Bank Details List

This section displays the generated list of employee bank details based on the search criteria. It serves as a reference for verifying account numbers, IFSC codes, and bank names associated with each faculty member.
