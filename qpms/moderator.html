Moderator Section

This module allows administrators to manage exam moderators. By clicking on the Moderator option in the main dashboard, the user is redirected to the dedicated Moderator Dashboard.

Search Moderators

In this section, the user can search for existing moderators within the system. Simply select the required criteria from the dropdown filters and click the Search button to view results.

Adding Moderators

1. Individual Registration

To register a single moderator manually, the user can click the Add Moderator button. This will open the registration form.

2. Bulk Upload (Import)

For adding multiple moderators at once, the system supports a bulk import feature via Excel. Click the Import Moderator button to begin.

Prerequisite: Before uploading, please download the system-generated Excel template. Ensure that the column headers are not modified and data is entered in the correct format to prevent import errors.

Once the import option is selected, the upload interface will appear as shown below:

Steps for Bulk Upload:

  1. Download the moderator upload template in Excel format by clicking the download icon.
  2. Fill in the required details in the Excel sheet and save the file.
  3. Use the Choose File option to select the completed Excel file from your system.
  4. Select the appropriate Session from the dropdown menu.
  5. Click Upload File to complete the bulk registration process.

Moderator List & Actions

The Moderator List section displays all registered moderators. Use the controls provided in the list view to manage accounts.

Available Actions:
  • Appointment Letters: Click Send to email the appointment letter to the moderator, or click View to preview the document.
  • Edit Details: Click the Edit icon/button to modify a moderator's information.
  • Remove User: Click the Delete option to remove a moderator from the system.
