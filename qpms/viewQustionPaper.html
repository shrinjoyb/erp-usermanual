View Question Paper

This module provides authorized users access to the digital repository of submitted question papers. After clicking the "View Question Paper" section from the main dashboard, the user is redirected to the search interface.

Search Question Papers

In this section, the user can search for specific question papers by filling in the required details such as Session, Course, Subject, and Paper Type.

Note: Ensure all mandatory filters are selected to retrieve accurate results.

Question Paper List & Downloads

After performing the search, the system displays a list of available question papers matching the criteria. This section allows users to view details and download the files.

Download Options:

Users can download the question papers in the following formats directly from the list:

  • PDF Format (Portable Document Format)
  • Word Format (Editable Document)
