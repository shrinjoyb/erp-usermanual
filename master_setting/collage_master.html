Master Settings > Institution Management

College Master

Manage affiliated colleges, update institution details, and maintain the central directory.

Accessing College Master

To begin, navigate to the "College Master" section within the Master Settings. Clicking this option will grant access to the College List dashboard.

College List Dashboard

The dashboard provides a comprehensive view of all registered colleges.

Available Actions:
  • Add College: Click the "Add College" button to register a new institution.
  • Delete: Remove a college from the list using the delete option.
  • Edit: Update existing details using the edit button.

Add New College

Administrators can register colleges into the system using two methods:

Manual Entry

Manually input the college name, code, and address in the provided form fields.

Bulk Upload

Register multiple colleges at once by uploading a formatted data file.

Format Requirement:
The Bulk Upload feature exclusively supports Excel (.xlsx) format. Please download the sample template before uploading data.

Edit College Details

If any institution's information changes, you can modify it easily.

Locate the specific college in the list and click the Edit option. This allows you to update the name, address, or other configuration settings without deleting the record.
