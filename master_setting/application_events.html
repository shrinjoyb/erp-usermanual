Master Settings > Application Configuration

Application Events

Manage system-wide application events, schedules, and notifications.

Accessing Application Events

To access this module, navigate to the sidebar menu and select "Application Events". This action will redirect the user to the central Application Event List dashboard.

Application Event List Dashboard

The Dashboard provides a comprehensive view of all scheduled and past events. Users can manage the lifecycle of an event directly from this interface.

Key Functionalities:
  • Add Event: Create a new event by clicking the "Add" button.
  • Edit Event: Modify existing event details via the edit option.
  • Delete Event: Remove an event from the system permanently.

University Event Add / Edit

This interface allows the user to input details for a new event or update information for an existing one.

1
Open Form

Click the Add button (for new events) or the Edit icon (for existing events).

2
Enter Details

Fill in the required fields such as Event Name, Date, Description, and Priority.

3
Save Configuration

Click the Submit/Update button to save changes to the system.
