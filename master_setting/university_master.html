University Master

Manage university records, bulk imports, and data modifications.

Accessing "University"

By clicking on the "University" option in the sidebar menu, the user can directly navigate to the "University List" page.

University List Dashboard

This is the main dashboard where the user can view all registered universities.

  • User can add a new university by clicking the "Add" option.
  • User can also edit existing university data from here.

Add University

There are two methods available for adding universities to the system.

1. Manual Entry

The user can add a university by filling up the details manually in the form fields.

2. Bulk Upload

The user is also allowed to add multiple universities at once using the "Bulk Upload" option.

Important Note:
The data must be in Excel (.xlsx) format to complete the upload successfully.

Edit an Existing University

The user can edit details of an existing university by clicking the "Edit" icon in the list.

1
Select University

Identify the university row you wish to modify.

2
Click Edit Icon

Click the pencil/edit icon to open the modification form.

3
Update Data

Change the necessary fields and save.
