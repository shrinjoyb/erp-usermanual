Master Settings > Access Control

User Master

Manage system users, control access privileges, and ensure account security.

Accessing User Master

To manage system accounts, locate the "User Master" section in the Master Settings menu. Selecting this option will grant access to the User List Dashboard.

User List Dashboard

The User List Dashboard is the administrative hub for account management. Authorized users can oversee all registered accounts from this interface.

Administrative Actions:
  • Add User: Create new user profiles using the "Add User" button.
  • Lock User: Temporarily restrict a user's access by clicking the lock option.
  • Edit/Delete: Update profile details or permanently remove users from the system.

Add New User

Administrators can onboard new users into the system via manual entry or bulk processing.

Manual Registration

Fill out the registration form with personal details, role assignment, and credentials.

Bulk Upload

Register multiple users simultaneously by uploading a verified Excel file.

Security Note:
Ensure all mandatory fields are correctly filled. For Bulk Upload, always use the system-generated Excel Template to prevent data corruption.

Edit & Manage Users

Maintain user data accuracy and system security by managing existing accounts.

By clicking the Edit option, administrators can update user information. Additionally, the Lock feature allows for immediate suspension of user access without deleting the account, useful for temporary leaves or security audits.
