Master Settings > Student Management

Upload Student Details

Bulk upload utility for importing comprehensive student records into the ERP system.

Accessing Student Upload

Navigate to the "Upload Student Details" section within the Master Settings. Clicking this option will directly redirect you to the Upload Student All Data dashboard.

Upload Student All Data

This section allows administrators to perform massive data imports for student records.

In this dashboard, users can upload student data using the Excel file format. This process ensures that student information—such as personal details, enrollment numbers, and course mapping—is updated efficiently in bulk.

Data Integrity Warning:
Please ensure the Excel file strictly follows the system's column structure. We highly recommend downloading the sample template below before preparing your data file.
