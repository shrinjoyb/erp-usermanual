Master Settings > Examination

Paper Type Master

Define and manage various paper types (Theory, Practical, Sessional) for the examination system.

Accessing Paper Type

To manage paper definitions, navigate to the "Paper Type" section within the Master Settings. Clicking this option will redirect you to the main dashboard.

Paper Type List Dashboard

This interface lists all existing paper types configured in the system.

Capabilities:
  • Add Paper Type: Click the button to create a new category (e.g., Core, GE, DSE).
  • Edit: Modify the name or attributes of an existing paper type.
  • Delete: Remove unused paper types from the list.

Add Paper Type & Bulk Upload

Users can add paper types manually or upload multiple types simultaneously using the bulk upload feature.

Manual Entry

Fill in the paper type name and code in the form to add a single entry.

Bulk Upload

Upload an Excel file to import multiple paper types at once.

Important Requirement:
Before performing a bulk upload, you must download and use the official system template. Uploading data in an incorrect format will result in errors.
