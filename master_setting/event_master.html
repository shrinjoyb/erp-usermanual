Master Settings > Event Management

University Events Master

Schedule academic events, manage deadlines, and organize university application timelines.

Accessing University Events

Navigate to the Master Settings menu. Locate and select the "University Events" option. This action will redirect you to the main Application Event List dashboard.

Application Event List Dashboard

The Application Event List is the command center for all scheduled activities. Administrators can monitor upcoming events and perform necessary actions from this interface.

Dashboard Actions:
  • Add Event: Click the "Add Event" button to create a new schedule.
  • Management: Use the action columns to Edit or Delete existing events directly from the list.

Add New Event

Define new academic or administrative events easily. The system supports both individual event creation and mass scheduling via bulk upload.

Single Entry

Fill in the event name, date, and description in the form to add a single event.

Bulk Upload

Use the "Bulk Upload" option to import multiple events simultaneously.

Bulk Upload Tip:
After clicking "Bulk Upload", download the provided Excel Template. Fill it with your event data and upload it back to ensure seamless integration.

Edit or Delete Events

Maintain an accurate schedule by modifying details or removing obsolete events.

  • Edit: Click the icon to update event details such as dates or descriptions.
  • Delete: Click the icon to permanently remove an event from the system.
