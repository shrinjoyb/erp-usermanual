Master Settings > User Management

Role Master

Define user roles, manage permissions, and track role assignments.

Accessing "Role"

Locate the "Role" section within the Master Table Settings. Clicking this option will directly redirect the user to the Role List Dashboard.

Role List Dashboard

The Role List serves as the central hub for viewing all defined roles within the organization.

Dashboard Features:
  • Add Role: Use the "Add Role" button to create new designations.
  • Member Count: The list displays a "Count" column, showing exactly how many members are currently assigned to each specific role.

Add New Role

Administrators can introduce new roles into the system using two methods: Manual Entry or Bulk Upload.

Manual Creation

Fill out the role name and description in the popup form to create a single role.

Bulk Upload

Upload multiple roles simultaneously using an external file.

Bulk Upload Requirement:
Ensure the uploaded file is in Excel (.xlsx) format and follows the system template to avoid import errors.
