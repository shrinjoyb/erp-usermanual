2. Search Teacher Module

2.1 Search Teacher Section

Navigate to the Teachers module. This section allows users to search for teachers using available search options. Users can quickly locate teacher records based on predefined criteria such as Department, Designation, or Name.

2.2 Teachers List Dashboard

This dashboard displays the complete list of registered teachers in a grid view. From here, you can manage records efficiently.

Key operational capabilities within this dashboard include:

  • Add New Records: Users can register new faculty members into the system by clicking the Add Teacher button.
  • Modify Details: Existing teacher profiles can be updated or corrected by selecting the Edit option from the action menu.
  • Quick Search: Specific teacher records can be instantly located by entering keywords in the dedicated Search Field.

2.3 Add New Teacher

To onboard a faculty member, click the Add Teacher button located at the top right of the dashboard.

Fill in the required details in the form. Ensure that you select the correct information from the predefined Dropdown Options (e.g., Department, Role) to maintain data consistency.

Note: Fields marked with an asterisk (*) are mandatory and cannot be left blank.

2.4 Edit Teacher Details

This section allows users to modify existing teacher records. To update information:

  1. Locate the teacher in the list.
  2. Click the Edit icon in the action column.
  3. Make necessary changes and click Submit.
