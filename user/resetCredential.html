3. Reset User Credential

3.1 Credential Management Overview

This module facilitates the secure management of user authentication. Administrators can navigate to this section to reset login credentials for both students and teachers.

3.2 Search Credentials

To locate a specific user account, utilize the search functionality. Users can filter records using the following criteria:

  • Search by Username: Enter the unique User ID.
  • Search by Registration Number: (If applicable) Locate users by current credential string.

3.3 Password Reset Action

To reset a user's access, locate the user in the list and click the Reset Icon.

This action will override the current password.

System Default: After a successful reset, the user's password will be automatically set to the default credential: abc123.
